## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13 compatible) does no network access, uses no randomness and no timestamps: it copies the bundled `entry.png` byte-for-byte to `/output/entry.png`. Running it twice produces byte-identical output.

`draw.py` is the script that rendered `entry.png` with Pillow; it is kept for transparency and is not needed to run the entry.
